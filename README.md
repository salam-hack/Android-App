# 💡 What is Modabber?

**Modabber** is an AI-powered personal finance app designed to help users easily track, understand, and improve their financial habits.

Instead of manually writing every expense, users can simply type a note, send a voice message, upload a receipt image, or even use notifications — and Modabber’s AI automatically converts them into organized financial transactions.

With its intelligent financial assistant, Modabber provides:
- Smart expense tracking
- Spending analysis
- Financial insights
- Budget awareness
- Savings goals
- Subscription & debt reminders

All through a simple and fast user experience built for everyday life.

# 🧭 How does Modabber work?

When the user opens the app, they instantly see a quick overview of:

- 💰 Current balance
- 📊 Spending analytics
- 📅 Recent transactions
- 🎯 Savings goals

Users can easily add expenses through multiple smart methods:

- ✍️ Writing a quick note
- 🎤 Voice input
- 📸 Receipt image scanning
- 🔔 Notification parsing

The AI automatically analyzes the input and creates organized transactions.

Users can also:
- Track subscriptions & debts
- Receive smart alerts for overspending
- Ask the AI assistant financial questions
- Set saving goals and monitor progress
